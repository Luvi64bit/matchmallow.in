# Matchmallow

Homepage for Matchmallow, a compatibility quiz you send to your partner, crush or bestie as a link.

**Tech:** static HTML with inlined CSS (`public/index.html`), a small demo script (`public/demo.js`), self-hosted Fredoka and Figtree WOFF2 subsets, hosted on Netlify. There is no build step.

**Run locally:** `netlify dev --port 8889`, or serve `public/` with any static file server.

**Still to build:** the quiz flow (`/start`), the share and result pages, the Privacy, Terms and Contact pages, and the data storage behind them.
